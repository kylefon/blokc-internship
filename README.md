# Coding Challenge Solution

This is my solution for the coding challenge: *INTERN01-FRONTEND-WEB3*

I have completed the challenge as described, fulfilling the following requirements:

1. **Connect Button**: A button labeled "Connect with MetaMask" is rendered, allowing the user to initiate the MetaMask connection.

2. **MetaMask Integration**: Upon clicking the button, the MetaMask browser extension opens, enabling the user to connect their wallet.

3. **Balance Display**: Once the user is connected, their wallet address and balance in ETH are displayed. It directly queries the Etherium Balance using the eth_getBalance method via MetaMask.
